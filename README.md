# IMSI Catcher Detector (без SDR, root не требуется)

Многосигнальный детектор аномалий сотовой сети для Android. Собран поверх
официальных `TelephonyManager`/`CellInfo` API — работает на любом
современном устройстве без root.

## Сборка

Открой в Android Studio или собери через GitHub Actions (`.github/workflows/build.yml`,
`gradle assembleDebug`).

## Архитектура

```
data/          — CellObserver, Room-сущности, DAO, GeoHash, DbKeyStore (SQLCipher passphrase)
analysis/      — ScoringEngine (многосигнальный скоринг с feedback-loop и OpenCellID), ThreatScore
network/       — OpenCellIdClient — сверка с внешней базой как вторичный сигнал
service/       — DetectorService (foreground-сервис, адаптивный polling, планирует WorkManager)
work/          — PeriodicCheckWorker — fallback-проверка, если сервис убит системой
sms/           — SilentSmsReceiver (детект class-0 SMS)
notification/  — NotificationHelper
ui/            — MainActivity, AlertsAdapter — карточный UI, тёмная тема с градиентом
```

## Реализованные улучшения

- **Адаптивный интервал сканирования** — чаще при движении/повышенном score.
- **Confidence вместо бинарного флага** — растёт на каждое повторное наблюдение соты.
- **Feedback loop, полностью реализован** — long-press на карточке алерта помечает
  его ложным; `ScoringEngine` считает долю ложных срабатываний по конкретной соте
  и дампит (снижает) score для неё в будущем, если доля превышает порог.
- **Geohash вместо постоянного точного GPS** — по умолчанию только кэшированная локация.
- **Explainable alerts** — каждый алерт хранит конкретные причины, показываются на карточке.
- **Тестовый режим, полностью реализован** — прогоняет синтетическое наблюдение
  через настоящий `ScoringEngine` (не просто фейковое уведомление), пишет в БД,
  проверяет весь пайплайн целиком.
- **Шифрование БД (SQLCipher)** — `AppDatabase` открывается через `SupportFactory`
  с passphrase, который генерируется один раз и хранится в `EncryptedSharedPreferences`
  поверх Android Keystore (см. `DbKeyStore.kt`). Passphrase никогда не хардкодится
  и не логируется.
- **Внешняя база (OpenCellID) как второй голос** — `OpenCellIdClient` спрашивает,
  известна ли сота глобально, если она неизвестна локально. Полностью опционально:
  без API-ключа, без сети или по таймауту сигнал просто не используется
  (никогда не считается подозрительным сам по себе). Ключ задаётся в
  `OpenCellIdClient.API_KEY` (получить бесплатно на opencellid.org).
- **WorkManager fallback** — `PeriodicCheckWorker` запускается каждые 15 минут
  (минимум для периодических задач в Android) как страховка на случай, если
  агрессивная экономия батареи убьёт foreground-сервис. Основной путь
  детекции — сервис в реальном времени; воркер — редкая подстраховка.
- **Интерфейс** — тёмная тема, градиентный статус-хедер с индикатором
  (зелёная точка = активен), карточки для каждого действия, RecyclerView
  с цветной полоской severity (синий/оранжевый/красный по score) вместо
  простого списка.

## "Максимальная прокачка" — что добавлено сверх базовой версии

- **Bluetooth/Wi-Fi корреляция** (`EnvironmentScanner.kt`) — хешированный
  (SHA-256, никогда не сырой MAC) отпечаток окружения; несовпадение
  привычного BT/Wi-Fi окружения одновременно с аномалией соты добавляет
  контекстный балл (никогда не работает как самостоятельный сигнал).
- **Классификатор режима движения** (`MovementClassifier.kt`) — три
  состояния (стоя/пешком/в транспорте) по дисперсии акселерометра вместо
  грубого bool; используется для масштабирования порога частоты
  хендоверов (в транспорте частая смена соты — норма, не тревога).
- **Профили мест** (`PlaceProfileClassifier.kt`) — два самых частых
  geohash-кластера считаются "домом/работой", остальное — "в пути";
  смена соты в основном месте весит больше, чем та же смена во время
  случайного перемещения.
- **Экспорт истории в CSV** (`ExportManager.kt`) — экспорт журнала
  алертов через системный share-intent (FileProvider, без прямых
  file:// путей).
- **Panic wipe** — кнопка полной необратимой очистки локальной истории
  (известные соты, наблюдения, алерты) с обязательным подтверждением.

### Что осознанно не реализовано (требует инфраструктуры за пределами кода)
- SDR-интеграция (независимый радио-источник) — нужно отдельное железо.
- Серверный краудсенсинг между пользователями — нужен бэкенд.
- Обученная on-device ML-модель — нужны размеченные данные и pipeline
  обучения; текущие пороги остаются эвристическими, но явно вынесены в
  константы для лёгкой донастройки.
- Root/diag-режим (реальная проверка шифрования канала) — требует root
  и совместимого чипсета, принципиально не то же самое, что этот проект.

## Честные ограничения (архитектурный потолок без SDR/root)

- Не проверяет реальное состояние шифрования радиоканала (A5/0 vs A5/1).
- Не ловит грамотное клонирование легитимной соты — нужен независимый
  источник данных (SDR), не встроенный модем.
- Timing Advance на части чипсетов Android не отдаёт через публичный API —
  соответствующий сигнал в этом случае молча отключается.
- OpenCellID-проверка требует собственного бесплатного API-ключа и сети;
  без них работает вся остальная логика, просто без этого одного сигнала.
